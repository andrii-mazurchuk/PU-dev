Build a one-way mirror from a GitHub repository's open issues into pu tasks: one task per open issue.

- One-way only. GitHub remains the source of truth for the issue body, so the task carries the issue URL rather than a copy of the body.
- Re-running the mirror must not create duplicates — an issue already mirrored is skipped or updated in place, not re-created.
- Reads open issues; closed issues are out of scope as the message did not mention them.

The repository to read from is a parameter of the tool, not fixed by the message.
